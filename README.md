# Image Processing algorithms from scratch using Python, NumPy, and OpenCV.

A comprehensive implementation of fundamental Computer Vision and Image Processing algorithms from scratch using Python, NumPy, and OpenCV.

This notebook demonstrates the mathematical foundations behind common image processing techniques instead of relying on built-in OpenCV functions.

---

## 📌 Overview

This project covers the implementation of several core Computer Vision concepts including:

- Image color space conversion
- Intensity transformations
- Image filtering
- Edge detection
- Noise removal
- Manual implementation of the Canny Edge Detection pipeline

The goal is to understand the underlying mathematics and algorithms behind traditional computer vision techniques.

---

## 🚀 Topics Covered

### Q1 – Image Representation

- RGB Image Loading
- Manual Grayscale Conversion
- Manual Binary Image Conversion
- Thresholding Analysis

---

### Q2 – Intensity Transformations

Implemented manually:

- Image Negative
- Log Transformation
- Gamma Correction
- Brightness & Contrast Analysis

---

### Q3 – Edge Detection

Implemented using:

- Roberts Operator
- Prewitt Operator
- Comparison of Edge Detection Methods

---

### Q4 – Image Denoising

- Gaussian Noise Generation
- Mean Filtering (3×3, 5×5)
- Gaussian Filtering
- Performance Comparison

---

### Q5 – Sobel Operator

Manual implementation of:

- Sobel X
- Sobel Y
- Gradient Magnitude
- Gradient Direction

---

### Q6 (Bonus) – Manual Canny Edge Detector

Complete pipeline implementation including:

- Gaussian Smoothing
- Sobel Gradient Calculation
- Non-Maximum Suppression (NMS)
- Double Thresholding
- Edge Tracking by Hysteresis
